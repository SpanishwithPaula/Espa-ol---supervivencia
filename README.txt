Versión ampliada de Empieza y Frases

Publicar en GitHub Pages:
1. Extrae este ZIP.
2. Sube index.html a la raíz del repositorio (reemplaza la versión anterior).
3. En Settings > Pages, selecciona Deploy from a branch y la carpeta raíz (/).
4. Abre la dirección de GitHub Pages del repositorio.

Los iconos y algunas fotografías de la versión original usan proveedores externos y necesitan internet.
El progreso y el cuaderno se almacenan localmente en el navegador cuando este lo permite.
